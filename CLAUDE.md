Read HANDOFF.md first: it has the goal, the decisions already made, the state of the code, what is unverified,
and the next steps. Commands: `npm test`, `npm run test:rules` (emulator, needs Java), `npm run typecheck`,
`npm run build`.

Keep CHANGELOG.md up to date: add a plain-language entry under "Unreleased" with every user-visible change, fix,
rules change or setup change, in the same commit as the change. When a version is deployed, rename "Unreleased"
to the version and date.
